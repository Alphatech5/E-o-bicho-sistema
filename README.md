<h3>📌 Sobre o Projeto</h3>

A É o Bicho é uma clínica veterinária com forte atuação social, focada em controle populacional por meio de castração e na promoção da adoção responsável.
O sistema foi concebido para atender duas frentes principais:
* Sistema Interno (ERP): Uma área administrativa restrita para a equipe da clínica, permitindo o gerenciamento de pacientes e o controle de agendamentos de consultas e cirurgias.

<h3>🚀 Funcionalidades</h3>

<h4>Sistema de Gestão</h4>

 * Cadastro de Pacientes: Prontuário digital com histórico do animal e dados do tutor. 
 * Agendamento Inteligente: Controle de datas para castrações e consultas clínicas.   
 * Dashboard Administrativo: Visão geral da operação da clínica.

<h3>🛠️ Tecnologias Utilizadas</h3>

 * Front-end: HTML, CSS
 * Back-end: Java
 * Banco de Dados: PosgreSQL
* Prototipagem: Figma
